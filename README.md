ProjectHub (WIP):
A personalized workspace dashboard built to streamline project management, notes, and research compilation. Designed with a calming, pastel-themed interface for focused development.

 Current Status:
This project is currently in active development.

Core Dashboard: View all your active projects with visual progress tracking.

Dynamic Workspace: Intuitive, tabbed interface to manage specific project assets (Notes, Links, Ideas, Diary, Milestones).

Tech Stack: React, Tailwind CSS, and a Node.js/Express backend (setup in progress).

🛠 Features to be Implemented
[ ] Persistence: Connecting the frontend state to a live database (PostgreSQL/Neon) to save notes and link data permanently.

[ ] Project Creation: Full modal functionality to initialize new project workspaces.

[ ] Authentication: Secure user login to access your personal project hub.

[ ] Backend API: Full CRUD operations for all workspace tabs.

⚙️ Getting Started
To run this project locally:

Clone the repository:

Bash
git clone https://github.com/s4eee/projecthub.git
cd projecthub
Install dependencies:

Bash
npm install
Run the application:

Bash
npm run dev

Design Philosophy
ProjectHub is built with a focus on "Calm Tech." The goal is to provide a clean, distraction-free environment that reduces cognitive load during intense coding sessions.

Current UI Theme: Pastel aesthetic with soft-shadow components.
